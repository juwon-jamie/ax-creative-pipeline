# "사용 가능한 영상 클립" 판정 기준서 v1

## 1. 판정 단위와 정의

| 항목 | 정의 |
|---|---|
| **판정 단위** | 이미지 1장에서 렌더된 영상 클립 1개 (통상 5–10초). 이미지 1장 → 렌더 n회면 클립 n개, 각각 별도 판정 |
| **모집단** | 해당 월에 생성된 **모든 이미지**. 렌더를 시도하지 않은 이미지도 분모에 들어간다 |
| **사용 가능 (USABLE)** | 컷 편집·자막·BGM 등 **후반 작업만으로** 캠페인 타임라인에 투입할 수 있는 클립. **재생성·리터치·프레임 삭제가 필요하면 불가** |
| **전환율** | 사용 가능 클립 수 ÷ 생성 이미지 수 (**렌더 시도 수가 아니다**) |
| **판정값** | 이진 — `USABLE` / `NOT_USABLE`. 불가는 반드시 탈락 코드 1개 이상 부착 |

전환율 분모를 "생성 이미지"로 잡는 이유: 이미지 단계 게이트(영상화 가능성 평가)의 효과까지 지표에 포함되어야 "이미지 단계에서 걸러서 렌더 성공률을 올렸다"는 서사와 숫자가 일치한다. 분모를 렌더 시도로 바꾸면 숫자는 더 좋아 보이지만 이야기와 어긋난다. **좋아 보이는 쪽을 택하지 않는다.**

## 2. 탈락 조건 (하나라도 해당 → NOT_USABLE)

Gate 3 항목과 1:1로 대응한다. 코드는 실패 학습 루프의 분류 키로도 쓴다.

| 코드 | 이름 | 조작적 정의 (채점자가 봐야 할 것) | Gate 3 항목 |
|---|---|---|---|
| **F1** | 형태 붕괴 | 인물·제품의 윤곽이 1프레임이라도 해부학적·구조적으로 불가능한 형태로 변함 (손가락 수, 관절 역방향, 제품 용기 찌그러짐) | 형태 왜곡·물리 오류 |
| **F2** | 모핑 | 피사체가 다른 물체·인물로 녹아 바뀜, 또는 배경이 흘러내림 | 깜빡임·모핑 |
| **F3** | 깜빡임·프레임 튐 | 조명·색·질감이 프레임 간 불연속. 0.5초 이상 지속되거나 2회 이상 발생 | 깜빡임·모핑 |
| **F4** | 물리 오류 | 중력·반사·그림자·액체 흐름이 현실과 모순 (제품 액체가 위로 흐름, 그림자 방향 불일치) | 형태 왜곡·물리 오류 |
| **F5** | 정지·무변화 | 시작 프레임과 종료 프레임 사이에 의도된 변화가 없음 (사실상 정지 이미지) 또는 카메라만 미세하게 흔들림 | 영상 전환 가능성 |
| **F6** | 브랜드·제품 위반 | 제품 형태·색·로고 영역이 레퍼런스와 식별 불가하게 다름, 브랜드 금지 요소 노출, 텍스트 깨짐 | 브랜드·제품 표현 |
| **F7** | 렌더 미완 | 길이·해상도·비율이 스펙 미달, 인코딩 깨짐, 워터마크·검은 프레임 포함 | 최종 렌더 완성도 |

> 채점자 지침: **F 코드가 하나라도 확실하면 즉시 NOT_USABLE.** 통과 조건은 볼 필요 없다. 애매하면 F 코드에 `?`를 붙이고 통과 조건으로 넘어간다.

## 3. 통과 조건 (전부 충족 → USABLE)

탈락 조건이 "결함이 없는가"라면 통과 조건은 "쓸 수 있는가"다. 결함이 없어도 쓸모없는 클립은 많다.

| 코드 | 이름 | 조작적 정의 |
|---|---|---|
| **P1** | 의도 일치 | 기획서·프롬프트에 적힌 장면 서술(피사체·동작·카메라)과 클립 내용이 일치. 채점자는 프롬프트 요약 1줄만 보고 판단 |
| **P2** | 스펙 충족 | 길이 ≥ 기획 길이의 80%, 해상도·비율 스펙 일치, 프레임 드롭 없음 |
| **P3** | 동작 자연스러움 | 피사체 움직임과 카메라 이동이 실사 촬영본으로 오인 가능한 수준. "AI 티"가 나도 **컷으로 잘라 쓸 수 있으면 통과** |
| **P4** | 제품 식별 | 제품(또는 브랜드 핵심 요소)이 클립 어느 구간에서든 1초 이상 명확히 식별 |
| **P5** | 시작·종료 상태 | 시작과 끝이 서로 다른 유의미한 상태이며, 앞뒤 컷과 이어붙일 수 있는 진입·이탈 프레임이 있음 |
| **P6** | 여백 | 자막·CTA·로고를 얹을 안전 영역이 확보됨 (핵심 피사체가 화면 하단 20%·상단 15%를 점유하지 않음) — 세로 숏폼 기준 |
| **P7** | 컷 투입 가능 | 채점자가 "이 클립을 지금 편집 타임라인에 얹겠는가?" 에 Yes. 위 6개가 다 통과여도 여기서 No면 사유를 적고 NOT_USABLE |

P7은 의도적으로 주관을 남긴다. 주관을 없애는 게 아니라 **주관의 위치를 명시하고, 그 주관이 채점자 간에 얼마나 일치하는지 숫자로 보이는 것**이 목표다.
